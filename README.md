# dotfiles

## Installation

```console
$ make
```

This will create symlinks from this repo to your home folder.

| Make argument | Notes                                          |
|---------------|------------------------------------------------|
| all           | cli and gui                                    |
| cli           | bash files, config, utilities, live-server     |
| gui           | regolith, terminal, backgrounds, themes, fonts |
